# Qvesys Lab – Integrated Web Project

Flow: Home (index.html) → Get Started → Sign In (signin.html) → OTP (otp.html) → Verify (verify.html) → Admin (admin.html) → Dashboard (dashboard.html)

## Run in VS Code
1. Open this folder in VS Code (File → Open Folder).
2. Install the "Live Server" extension (Ritwick Dey).
3. Right-click index.html → "Open with Live Server".
4. Internet is needed for Google Fonts and Font Awesome icons.

## Demo details
- Sign In: any username + password, then solve the math question.
- OTP: shown in the yellow "Demo mode" box (no email server is connected).
- Admin password: admin123 (change it in js/config.js).
